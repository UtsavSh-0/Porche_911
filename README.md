# 🏎️ Porsche 911 Turbo S — Cinematic Landing Page

A premium, luxury automotive landing page inspired by Porsche's design philosophy, featuring a full-screen cinematic hero video, immersive scroll animations, performance storytelling, and modern web technologies.

![Porsche 911 Turbo S](./public/preview.jpg)

---

## ✨ Features

### 🎥 Cinematic Hero Section

* Full-screen video background
* Autoplay, loop, muted playback
* Dynamic dark overlay
* Mouse-based parallax effects
* Premium typography animations

### ⚡ Performance Showcase

* Animated performance metrics
* Count-up statistics
* Scroll-triggered transitions
* Motion-driven storytelling

### 🔧 Technical Specifications

* Interactive specification cards
* Staggered animations
* Luxury glassmorphism design
* Responsive layouts

### 🚗 Immersive Gallery

* Horizontal scrolling experience
* High-quality vehicle imagery
* Smooth inertia effects
* Mobile optimized

### 🎨 Modern UI/UX

* Dark luxury theme
* Glassmorphism components
* Gradient lighting effects
* Smooth scrolling
* Micro-interactions
